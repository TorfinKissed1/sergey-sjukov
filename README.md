# Полусухая стяжка от Сергея Жукова — обновлённый лендинг

Статичный лендинг без сборки и внешних библиотек.

## Структура

```text
ui_kits/website/
├── index.html
├── assets/
│   ├── css/styles.css
│   ├── js/app.js
│   └── img/construction-ghost.svg
└── README.md
```

## Что изменено

- Убрана секция калькулятора внутри сайта. Вместо неё оставлена форма заявки на предварительный расчёт.
- Тексты переписаны как клиентские: без описания внутренней логики, MAX-бота и комментариев для разработчика.
- Основные направления соответствуют логике расчёта: квартира, частный дом, коммерческий объект.
- Секция услуг сделана как pinned/sticky-блок: на десктопе экран «застывает», а карточки услуг поочерёдно меняются при скролле.
- Добавлена строительная SVG-графика в середине сайта: она двигается за контентом как полупрозрачный фоновый слой.
- Добавлены SVG-иконки в услуги, блок качества, этапы и контакты.
- Footer облегчён под лендинг.
- Адаптив сделан fluid-first с контрольными брейкпоинтами: 1440, 1240, 1024, 768, 480, 360.
- Учтён `prefers-reduced-motion`: пользователи с отключённой анимацией получают статичную версию.

## Файлы для правки

- Контент и разметка: `index.html`
- Визуал и адаптив: `assets/css/styles.css`
- Анимации, меню, форма: `assets/js/app.js`
