# Полусухая стяжка от Сергея Жукова

Статичный лендинг без сборки и внешних библиотек. Страница готовится так, чтобы позже её было удобно перенести в WordPress: контент остаётся в HTML, стили — в BEM-классах, поведение — на `data-*` хуках.

## Структура

- `index.html` — главный лендинг, секции, формы и контакты.
- `privacy.html` — политика конфиденциальности.
- `thanks-short.html` — страница спасибо для короткой формы из блока калькулятора.
- `thanks-long.html` — страница спасибо для подробной формы из финального блока заявки.
- `assets/css/styles.css` — визуальная система, адаптив, анимации.
- `assets/js/app.js` — preloader, sticky-блок услуг, меню, маска телефона и статичная обработка форм.
- `assets/img/` — локальные изображения и SVG.

## Формы и цели

На странице две формы обратной связи:

- короткая форма `#quick-lead-form` в блоке `#quick-cta`;
- подробная форма `#lead-form` в блоке `#lead`.

Сейчас отправка сделана статично: после успешной клиентской валидации JS берёт `data-thanks-url` у формы и переводит пользователя на нужную страницу спасибо.

- короткая форма ведёт на `thanks-short.html`;
- подробная форма ведёт на `thanks-long.html`.

Страницы спасибо показывают короткое подтверждение и через `1500ms` автоматически возвращают пользователя на `index.html`. Кнопка `Вернуться` остаётся как ручной fallback. При переносе на WordPress эти страницы можно заменить шаблонами или обработкой формы, а URL оставить как отдельные цели для Яндекс Директа.

## Запуск

```powershell
py -m http.server 8000
```

Открыть `http://localhost:8000`.

## Публикация

Перед публикацией проверить актуальность телефона, почты, ссылок Max и VK, реквизитов и подключить реальный обработчик форм, если заявки должны уходить на сервер или в CRM. VK сейчас оставлен заглушкой до появления реальной ссылки на сообщество или профиль.
